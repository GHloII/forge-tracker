# Frontend instructions

- Use the existing Svelte, TypeScript, Vite, and Tailwind conventions.
- For small, direct UI edits, follow the fast path in the root `AGENTS.md`: skip reference reading and all checks.
- For other frontend changes, run `npm run check` and `npm run build` from `frontend`.
- Backend checks are required only when backend code, backend build configuration, or shared API contracts also change.
